# Phrase by phrase — тренажёр разговорных фраз

Одна страница без сервера и регистрации: русская фраза → собрать её на английском или немецком из плиток
(или набрать с клавиатуры), затем послушать образец, произнести и сравнить. Общение с владельцем — по-русски,
простыми словами.

## Файлы

- `index.html` — собранная страница. Руками не править: она пересобирается.
- `src/trainer.template.html` — вся разметка, стили и код. Данные фраз в ней — метки `/*DATA*/` и `/*DATA_DE*/`.
- `data/en.json` — английские фразы (160, по 40 на A2, B1, B2, C1).
- `data/de/<уровень>.txt` — немецкие фразы, по строке на фразу:
  `русская фраза | слова | два лишних слова | другие верные порядки через " ; " | разбор`.
- `build.mjs` — сборка и проверка данных. `.claude/launch.json` — локальный сервер для просмотра.

## Работа

- Собрать: `node build.mjs`. Ошибка в данных останавливает сборку и называет строку.
- Посмотреть: сервер `phrase-trainer` из `.claude/launch.json`, адрес `http://127.0.0.1:8765/`.
  Владелец запускает страницу сам двойным щелчком по `start-local.bat` (тот же адрес; его настройки и история
  в браузере привязаны именно к `127.0.0.1:8765`, порт не менять).
- Опубликовать: коммит и `git push` в `main` — GitHub Pages отдаёт `index.html` из корня,
  `https://123vit.github.io/phrase-trainer/`, сборка около 20 секунд. Публиковать только по слову владельца.
  Репозиторий публичный: в файлах не должно быть личных данных и путей с компьютера, автор коммита —
  служебный адрес GitHub (`…+123vit@users.noreply.github.com`), без строк об ИИ в сообщении.

## Что нельзя потерять при правках

- Всё помещается на один экран рабочего стола, прокрутки нет нигде. Разбор фразы — в левой панели, развёрнутый.
- Блок микрофона: выбор микрофона, индикатор уровня, ползунок усиления, «Авто», «Проверить».
- «Произнести и сравнить» заодно записывает попытку; её слушают кнопкой «Моя запись». Все записи удаляются
  при смене фразы.
- Кнопки «Произнести и сравнить» и «Записать» на время своего действия сами становятся «Стоп».
- Язык переключается двухпозиционным ползунком «Английский / Немецкий» в левой панели, не выпадающим списком.
- «Медленно» — та же фраза целиком в пониженном темпе, не по словам.
- История (уровень, место в раунде, результаты) хранится в браузере отдельно для каждого языка;
  «Сохранять историю» и «Очистить историю» — внизу страницы.
- Настройки в `localStorage`: `ept-theme`, `ept-lang`, `ept-input`, `ept-mic-gain`, `ept-mic-device`,
  `ept-voice-consent`, `ept-history`, `ept-history-de`, `ept-history-on`. Формат истории не ломать: у людей она есть.

## Как проверять

- Во встроенном браузере микрофон закрыт, `requestAnimationFrame` не срабатывает, пока панель не рисуется,
  распознавание речи недоступно, немецкого голоса нет.
- Звук проверяется подстановкой: открыть `http://127.0.0.1:8765/__blank__` (404), скачать страницу через `fetch`
  и записать её `document.write`, вставив перед первым `<script>` свой скрипт. В нём подменить
  `navigator.mediaDevices.getUserMedia` (поток от осциллятора), `requestAnimationFrame` (на `setTimeout`),
  при необходимости `SpeechRecognition` и `enumerateDevices`. Имена `DATA`, `LEVELS`, `LANGS`, `$`, `lang`
  заняты страницей — в подставном скрипте их не объявлять.
- Числа, а не впечатление: уровень на индикаторе, пик записанного сигнала (`decodeAudioData` по записи),
  аргумент `recognition.start`.
- Раскладку проверять на самой длинной фразе уровня C1 с подсказкой и с результатом распознавания:
  переполнения панелей при 1366×650 и больше быть не должно.
- Живой голос, темп озвучки и немецкое произношение проверяет владелец в Chrome — в отчёте прямо писать,
  что это не проверено.
- Немецкие фразы носителем не вычитаны.
